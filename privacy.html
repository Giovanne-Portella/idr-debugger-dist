Política de Privacidade

Extensão: Mapeador de Jornada — IDR Studio
Desenvolvedor: Robbu (uso interno)
Última atualização: junho de 2026

1. Coleta de dados

Esta extensão não coleta, transmite nem armazena dados em servidores externos. Todas as informações geradas ou armazenadas pela extensão permanecem exclusivamente no dispositivo do usuário, por meio do armazenamento local do navegador (chrome.storage).

2. Dados armazenados localmente

A extensão pode armazenar localmente:

  • Preferências de interface do usuário
  • Cache de dados de jornadas IDR visualizadas durante a sessão
  • Credenciais de autenticação WebAuthn (Windows Hello), armazenadas de forma criptografada apenas no dispositivo

Esses dados são usados exclusivamente para o funcionamento dos recursos da extensão e podem ser removidos a qualquer momento desinstalando a extensão.

3. Acesso a páginas e APIs

A extensão acessa a interface e as APIs do Invenio Center (inveniocenter.robbu.global) para ler e exibir dados de jornadas IDR. Esses dados são processados localmente e nunca enviados a terceiros.

4. Compartilhamento de dados

Nenhum dado do usuário é vendido, transferido ou compartilhado com terceiros.

5. Público-alvo

Esta é uma ferramenta de uso exclusivo por colaboradores internos da Robbu. Não é destinada ao público geral.

6. Contato

Dúvidas sobre esta política podem ser enviadas para giovannepm97@gmail.com.
